# Design proofs

`bucket-light.png`, `bucket-dark.png`, `gallery-light.png`, and `gallery-dark.png` are layout proofs drawn from the chrome tokens (`Scripts/design-layout-proof.py`). They are not SwiftUI screenshots.

On a Mac, `DesignSnapshot.write` (or `GRAILS_DESIGN_SNAPSHOT=<directory>` while the Design Gallery is open) renders the same names with `ImageRenderer` and replaces these proofs.
