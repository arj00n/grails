## What Grails is
A native macOS visual reference library (Swift 6, SwiftUI + AppKit, XcodeGen, SPM packages `GrailsKit` and `GrailsDesign`). Local first, no server, no account. A library is a plain folder (`*.grails`); teams share it through Google Drive or Dropbox. Chrome extension `Extensions/chrome` (v0.2.4). Marketing site: static, `site/`, on Vercel, served at https://grails.arjoon.xyz behind Cloudflare. Repo: `github.com/arj00n/grails` (private; renamed from `stash`). Support mail `hi@arjoon.xyz` (Cloudflare Email Routing to the owner's inbox).

### Steps
1. **Check by hand first** (cannot be automated; the owner has asked to approve critical visual changes before they ship). Build and install locally (below), then confirm with the owner, or look yourself if you can drive the UI:
   - Onboarding: Get Started, Import boards, press the **back chevron** and **Esc**: Choose must reappear with the ink band. Also from "Where it lives".
   - The Dock/Finder icon shows the new one (run `killall Dock`; Finder may cache).
   - Open `dist/Grails-<version>.dmg`: background fills the window, arrow between the icons, icon names readable in **both** light and dark Finder appearance.
   - Click-vs-drag on a tile; hover video; info panel appears with a selection.
2. **Bump the version** in `project.yml`: `MARKETING_VERSION: "0.3.2"`, `CURRENT_PROJECT_VERSION: "4"` (Sparkle compares the build number; it must be higher than every item in `site/appcast.xml`). Commit.
3. **Cut it:** `Scripts/release.sh 0.3.2 4`. Builds Release, makes the DMG, signs it with the Sparkle key, copies it to `site/download/`, updates `site/release.json`, prepends the item to `site/appcast.xml`. It refuses a version or build already in the appcast. It publishes nothing.
4. **Site strings.** Replace `0.3.1` with `0.3.2` in `site/index.html`, `404.html`, `privacy/index.html`, `credits/index.html` (hero link, install step, JSON-LD `softwareVersion`, footer `meta` version/date, the `NN.N MB` size from the new DMG) and in `site/vercel.json` (the `/download` redirect and the `Content-Disposition` filename). Bump `?v=` on any CSS/JS you changed (assets are cached immutable for a year).
5. **Deploy:** `cd site && vercel deploy --prod --yes` (project `grails`, team `workarjunvijay-7071s-projects`). The DMG and the appcast go live together.
6. **Purge Cloudflare** (it caches the DMG and the appcast at the edge): `cf cache purge -z df44a69ec45efdde3cec2eee1bde78b3 --force --body '{"files":["https://grails.arjoon.xyz/appcast.xml","https://grails.arjoon.xyz/download/Grails-0.3.2.dmg","https://grails.arjoon.xyz/","https://grails.arjoon.xyz/download"]}'`. If `cf` says you are logged out, run `cf auth login` (browser approval by the owner; the token lasts about 6 hours).
7. **Verify live:** the appcast shows 0.3.2 on top; `curl -sI .../download/Grails-0.3.2.dmg` has the right `content-length`; the downloaded file's sha256 equals `site/release.json`; `/download` redirects to it. Then on a Mac with 0.3.1 installed, Grails > Check for Updates should offer 0.3.2.
8. **Install locally and reset:** copy `build/dmg/Grails.app` to `/Applications` and run `Scripts/reset-app.sh` (the owner tests onboarding fresh after every install).
9. **Push:** `git push origin main`. Local commits are not pushed until the owner says so; "hand off to build and publish" covers this release, but ask if anything unexpected turned up.

## Build, test, run
- Generate and build: `xcodegen && xcodebuild -project Grails.xcodeproj -scheme Grails -configuration Debug -destination 'platform=macOS,arch=arm64' build`. Afterwards run `git checkout Packages/GrailsKit/Package.resolved` (Xcode adds a Sparkle pin each time; do not commit it).
- Kit tests: `cd Packages/GrailsKit && swift test --scratch-path .build-collab --filter <Suite>`. **Never run the whole suite**: it hangs. Run the suites you touched.
- Headless checks (they write `result.txt` ending `PASS`/`FAIL` and PNGs): `GRAILS_ONBOARDING_DEMO=<dir> GRAILS_ONBOARDING_DEMO_QUIT=1 <DerivedData>/Debug/Grails.app/Contents/MacOS/Grails`; also `GRAILS_COLLAB_DEMO=<dir>` and `GRAILS_HOVER_DEMO=<dir>` (see `PROGRESS.md`). **Quit every running Grails first** (`pkill -x Grails`): a second instance makes a demo hang.
- Window capture for UI checks without screen-recording permission: `GRAILS_SNAPSHOT=<png> GRAILS_SNAPSHOT_DELAY=<s> GRAILS_SNAPSHOT_QUIT=1` also writes `<png>.window.png` (the real composited window) when the ink band view is on screen. Dev hooks: `GRAILS_ONBOARDING_CHOOSE=1`, `GRAILS_ONBOARDING_AUTOSTART=1`, `GRAILS_ONBOARDING_BACKTEST=1|paste`, `GRAILS_OPEN_FEEDBACK=1`.
- Release build for installing: use a clean worktree so half-edited files never ship: `git worktree add --detach /tmp/wt HEAD && cd /tmp/wt && bash Scripts/make-dmg.sh`, then copy `build/dmg/Grails.app`. `dmgbuild` lives in `~/.local/share/grails-dmg/bin/dmgbuild` (without it the DMG falls back to the plain layout).
- Synthetic mouse clicks (CGEvent) do not reach the app on this Mac (no Accessibility permission), so real clicks must be tried by a person.
