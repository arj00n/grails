Questions

How is Grails different from Are.na or Pinterest?

Those keep boards in the cloud. Grails brings them onto your Mac as a fast local library you own, then lets the team share that library through a normal synced folder.

How is it different from Eagle or Atlas?

Same idea of a native Mac reference library. Grails is free and open source, built for a shared team folder, and imports Are.na, Pinterest and X boards so you don’t start empty.

How does team sharing work with no server?

The library is a plain folder. Put it on Drive, Dropbox or iCloud, invite the team there, and each person opens the same folder in Grails.

Can I bring what I already have?

Yes. Paste a board link to import it as a collection. Files stay yours on disk.

Is it free?

Yes. No account, no trial wall.
